۰. این راهنما چیست

نصب کامل AURION روی ویندوز. محصول فقط دسکتاپ ویندوز است. پیش‌نیازها (پایتون ۳.۱۲ و Node.js ۱۸+) اگر روی رایانه نباشند خود نصب‌کننده دانلود و نصب می‌کند. دادهٔ ساختگی وجود ندارد: تا AurionBridge روی چارت زنده ننشیند میز خالی می‌ماند.

اپ رسمی MetaTrader 5 موبایل نمی‌تواند EA نگه دارد. Android SDK، Flutter و APK بخشی از AURION نیستند و از درخت پروژه حذف شده‌اند. اجرا فقط روی ویندوز یا VPS ویندوز است.

۱. چه چیزی نصب می‌شود

قطعهکجاچگونه نصب می‌شود

۲. ویندوز — یک بار، یک کلیک

  1. کل پوشهٔ AURION را در D:\aurion بگذارید (نه تو در تو: D:\aurion\aurion غلط است).
  2. روی install-aurion.cmd دوبار کلیک کنید. پنجره باز می‌ماند تا پیشرفت را ببینید.
  3. اگر پایتون ۳.۱۲ یا Node نباشد، نصب‌کننده آن‌ها را می‌گیرد (winget، وگرنه دانلود رسمی).
  4. سپس pip و npm اجرا می‌شود و AurionBridge.mq5 داخل MQL5\Experts\Aurion هر ترمینال محلی کپی می‌شود.
  5. در پایان میز در http://127.0.0.1:8080 باز می‌شود.

از دفعهٔ بعد فقط start-aurion.cmd کافی است. اگر پیش‌نیازی ناقص باشد همان اسکریپت خودش نصب‌کننده را صدا می‌زند. توقف: stop-aurion.cmd.

نصب پایتون/نود ممکن است چند دقیقه طول بکشد و به اینترنت نیاز دارد. اگر PATH تازه نشده باشد یک‌بار از حساب ویندوز خارج شوید یا نصب‌کننده را دوباره اجرا کنید.

۳. اولین ورود به میز

  1. مرورگر http://127.0.0.1:8080 را باز می‌کند.
  2. اولین اجرا مدیر می‌سازد. گذرواژهٔ کارخانه‌ای وجود ندارد — خودتان بسازید.
  3. ورود با Gmail یا شمارهٔ ایران (09xxxxxxxxx).
  4. زبان را از EN / فارسی / العربية انتخاب کنید.
  5. تا EA روی چارت نباشد بازار و پوزیشن خالی است. این درست است.

۴. متاتریدر ۵ و EA ۱.۱۷

  1. ترمینال بروکر را نصب و وارد حسابی شوید که مجاز به معاملهٔ آن هستید.
  2. در MetaEditor فایل D:\aurion\engine\ea\AurionBridge.mq5 (یا کپی داخل Experts\Aurion) را با F7 کامپایل کنید. نسخه باید ۱.۱۷ باشد.
  3. اکسپرت را روی هر چارتی که باید روی میز بیاید بچسبانید. AutoTrading سبز باشد. Strategy Tester نه.
  4. تب Experts باید بگوید hello delivered v1.17 یا file inbox writing.
  5. WebRequest اختیاری است. اگر می‌خواهید HTTP هم کار کند در Tools → Options → Expert Advisors این‌ها را به allow-list اضافه کنید: 127.0.0.1 ، http://127.0.0.1 ، http://127.0.0.1:18765 ، http://127.0.0.1:8080.

ورودی‌های EA: InpEngineHost=127.0.0.1 روی همان PC، در غیر این صورت IP موتور. InpHttpPort=18765.

۵. چک‌لیست بعد از نصب

  1. http://127.0.0.1:8080/api/health مقدار backend: online و engine: online.
  2. قرص هدر: موتور زنده، بعد از EA متاتریدر زنده.
  3. کندل بازارها یکی‌به‌یک با چارت MT5.
  4. سفارش دستی میز در Toolbox → Trade ظاهر شود.

0. What this guide is

Full AURION install on Windows. This product is Windows-only. If Python 3.12 or Node.js 18+ is missing, the installer downloads and installs them. Nothing is invented: the desk stays empty until AurionBridge sits on a live chart.

Official MetaTrader 5 mobile cannot host EAs. The Android SDK, Flutter, and APK path are not part of AURION and have been removed from the tree. Execution is always on Windows or a Windows VPS.

1. What gets installed

PieceWhereHow
Python 3.12Host Windows PCwinget or official python.org silent setup
Node.js 18+ (22 / 26)Same PCwinget or official MSI
Engine wheels (NumPy 1.26.4 …)Same PCpip from engine\requirements.txt
Node deskSame PCnpm install in backend
AurionBridge 1.17Each local MT5 Experts folderCopied by the installer
Python must be 3.12 (not 3.13/3.14). Node 18+ including 26 is accepted. No Android SDK is required or shipped.

2. Windows — once, one click

  1. Put the whole tree at D:\aurion (not nested D:\aurion\aurion).
  2. Double-click install-aurion.cmd. The window stays open so you can see progress.
  3. Missing Python 3.12 or Node? The script installs them (winget, else official download).
  4. Then pip + npm, and AurionBridge.mq5 is copied into every local MQL5\Experts\Aurion.
  5. The desk opens at http://127.0.0.1:8080.

After that, start-aurion.cmd is enough. If a prerequisite is missing it calls the same installer. Stop with stop-aurion.cmd.

Python/Node setup needs the internet and a few minutes. If PATH is stale, sign out of Windows or run the installer again.

3. First desk login

  1. Browser opens http://127.0.0.1:8080.
  2. First launch creates the administrator. There is no factory password.
  3. Sign in with Gmail or an Iranian mobile (09xxxxxxxxx).
  4. Pick EN / فارسی / العربية.
  5. Until an EA is on a chart, markets and positions stay empty. That is correct.

4. MetaTrader 5 and EA 1.17

  1. Install the broker terminal. Log into an account you are allowed to trade.
  2. In MetaEditor compile D:\aurion\engine\ea\AurionBridge.mq5 with F7. Version must be 1.17.
  3. Attach it to every chart you want on the desk. AutoTrading green. Not Strategy Tester.
  4. Experts must show hello delivered v1.17 or file inbox writing.
  5. WebRequest is optional. If you want HTTP too, allow-list 127.0.0.1, http://127.0.0.1, http://127.0.0.1:18765, http://127.0.0.1:8080.

EA inputs: InpEngineHost=127.0.0.1 on the same PC, otherwise the engine IP. InpHttpPort=18765.

5. After-install checklist

  1. http://127.0.0.1:8080/api/health → backend: online and engine: online.
  2. Header pills: engine live, then MT5 live after the EA.
  3. Markets candles match the MT5 chart one-for-one.
  4. A manual desk order appears in Toolbox → Trade.

٠. ما هذا الدليل

تثبيت AURION على ويندوز فقط. إذا لم يوجد Python 3.12 أو Node.js 18+ فإن المثبّت ينزّلهما ويثبّتهما. لا بيانات مختلقة: يبقى المكتب فارغاً حتى يُرفَق AurionBridge على رسم حي.

تطبيق MetaTrader 5 الرسمي على الجوال لا يشغّل المستشارين. Android SDK وFlutter وAPK ليست جزءاً من AURION وحُذفت من الشجرة. التنفيذ على ويندوز أو VPS ويندوز فقط.

  1. ضع الشجرة كاملة في D:\aurion.
  2. انقر مرتين install-aurion.cmd. تبقى النافذة مفتوحة لترى التقدّم.

٣. أول دخول

  1. المتصفح يفتح http://127.0.0.1:8080.
  2. الإطلاق الأول ينشئ المدير. لا كلمة مرور مصنع.
  3. ادخل بـ Gmail أو رقم إيراني (09xxxxxxxxx).
  4. اختر EN / فارسی / العربية.
  5. بلا مستشار على الرسم تبقى الأسواق فارغة. هذا صحيح.

٤. ميتاتريدر وEA 1.17

  1. ثبّت طرفية الوسيط وادخل حساباً يحق لك تداوله.
  2. في MetaEditor جمّع AurionBridge.mq5 بـ F7. الإصدار 1.17.
  3. أرفقه على كل رسم تريده في المكتب. AutoTrading أخضر. ليس المختبر.
  4. Experts: hello delivered v1.17 أو file inbox writing.
  5. WebRequest اختياري. للقائمة: 127.0.0.1 وhttp://127.0.0.1 وhttp://127.0.0.1:18765 وhttp://127.0.0.1:8080.

٥. قائمة التحقق

  2. الحبوب في الرأس: المحرك ثم MT5 بعد المستشار.
  3. شموع الأسواق تطابق رسم MT5.
  4. أمر يدوي يظهر في Toolbox → Trade.
