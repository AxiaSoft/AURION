# دليل تثبيت AURION (العربية)

AURION لا يخترع سوقاً. بعد التثبيت يبقى المكتب فارغاً حتى يُرفَق AurionBridge على رسم حي.

## ويندوز — نقرة واحدة (موصى به)

1. انسخ الشجرة كاملة إلى `D:\aurion`.
2. انقر مرتين **`install-aurion.cmd`**.
3. إن نقص Python 3.12 أو Node.js LTS فإن السكربت **ينزّلهما ويثبّتهما** (winget أولاً ثم الملفات الرسمية).
4. ثم pip (NumPy **1.26.4**) و`npm install` ونسخ `AurionBridge.mq5` إلى كل `MQL5\Experts\Aurion` محلي.
5. يفتح المكتب على `http://127.0.0.1:8080`. الإطلاق الأول ينشئ المدير — لا كلمة مرور مصنع.

بعدها يومياً **`start-aurion.cmd`**. إن نقص متطلب يُستدعى المثبّت نفسه. الإيقاف: **`stop-aurion.cmd`**.

يحاول المثبّت السماح بالمنفذ **8080** في جدار ويندوز (Private) كي يصل المكتب المحلي على نفس الجهاز. إن رُفض فأعد التشغيل كمسؤول أو أضف المنفذ يدوياً.

لا تستخدم Python 3.13/3.14. AURION يستدعي `py -3.12` فقط. Node 18 فأعلى (ومنها 26) مقبول.

الدليل التفاعلي بثلاث لغات: `apps/web/guide-install.html` أو `http://127.0.0.1:8080/guide-install.html`.

## ماذا يضع المثبّت

| القطعة | الطريقة |
|---|---|
| Python 3.12 | winget أو تثبيت python.org الصامت |
| Node.js 18+ (22 أو 26) | الموجود أو winget أو MSI |
| المحرك | `py -3.12 -m pip install -r engine\requirements.txt` |
| حزمة MetaTrader5 | إن وُجدت العجلة |
| المكتب | `npm install` في `backend` |
| ملف المستشار | يُنسخ إلى Experts |

## ميتاتريدر 5 وEA 1.17

1. ثبّت طرفية الوسيط وادخل حساباً يحق لك تداوله.
2. MetaEditor → `AurionBridge.mq5` → **F7**. الإصدار **1.17**.
3. أرفقه على كل رسم تريده في المكتب. AutoTrading أخضر. ليس المختبر.
4. Experts: `hello delivered v1.17` أو `file inbox writing`.
5. WebRequest اختياري. للقائمة: `127.0.0.1` و`http://127.0.0.1` و`http://127.0.0.1:18765` و`http://127.0.0.1:8080`.

المدخلات: `InpEngineHost=127.0.0.1` على نفس الجهاز و`InpHttpPort=18765`.

## ويندوز فقط

AURION لا يضم تطبيقاً لأندرويد ولا APK ولا مشروع Flutter ولا Android SDK. تطبيق MT5 الرسمي على الجوال **لا يشغّل** المستشارين. المكتب: `http://127.0.0.1:8080`.

## تأكيد التثبيت

- `/api/health` يقول `online` للمحرك والمكتب
- حبوب الرأس: المحرك ثم MT5 بعد المستشار
- شموع الأسواق تطابق الرسم
- أمر يدوي يظهر في Toolbox → Trade
