# پیش‌نیازها روی یک سیستم خام

<div dir="rtl">

## خلاصه

روی یک ویندوز تازه، **لازم نیست چیزی را از قبل نصب کنید**. نه پایتون، نه Node.js.
ستاپ خودش تشخیص می‌دهد چه چیزی نیست و خودش نصبش می‌کند.

## چه چیزی نصب می‌شود

| چیزی که نیست | ستاپ چه نصب می‌کند | از کجا | دسترسی مدیر |
|---|---|---|---|
| Python ۳٫۱۰ تا ۳٫۱۲ | Python 3.12، فقط برای همین کاربر، روی `PATH` | python.org | لازم نیست |
| کتابخانه‌های موتور | `pip install -r engine\requirements.txt` | PyPI | لازم نیست |
| Node.js نسخهٔ ۱۸ به بالا | Node.js 20 | nodejs.org | **لازم است** |
| کتابخانه‌های دسک | `npm install` داخل `backend\` | npm | لازم نیست |
| WebView2 | نسخهٔ همیشه‌به‌روز، اگر ویندوز نداشته باشد | Microsoft | لازم نیست |

فقط Node.js پنجرهٔ UAC می‌آورد، چون نصاب خودِ Node برای کل سیستم است. نصب خود
اوریون همچنان به دسترسی مدیر نیاز ندارد.

## چه زمانی اجرا می‌شود

سه مسیر، و بین‌شان همهٔ حالت‌ها پوشش داده می‌شود:

1. **آخر ویزارد نصب.** صفحهٔ «Environment check» می‌گوید چه چیزی نیست، و وقتی
   Finish را می‌زنید پنجرهٔ نصب پیش‌نیازها باز می‌شود. اگر تیک «Start AURION now»
   را زده باشید، خودِ بالا آمدن برنامه همین کار را می‌کند و پنجرهٔ جدا باز نمی‌شود.
2. **نصب بی‌صدا** (`/qn`، `/qb`، `/qr`). صفحهٔ پایانی وجود ندارد، بنابراین
   پیش‌نیازها بعد از `InstallFinalize` نصب می‌شوند.
3. **هر بار اجرای اوریون.** اگر بعداً پایتون از روی سیستم برداشته شود، به جای خطا
   دوباره همان پنجره را می‌بینید.

برای اجرای دستی هر وقت خواستید:

```
AURION.exe --setup
```

`start-aurion.cmd` هم اگر پیش‌نیازی کم باشد دیگر فقط پیغام نمی‌دهد و بیرون
نمی‌آید — همین پنجره را باز می‌کند و بعد خودش دوباره تلاش می‌کند.

## چه چیزی نصب **نمی‌شود**

هیچ رانتایمی داخل فایل MSI بسته‌بندی نشده است. دو دلیل:

- نسخهٔ بسته‌بندی‌شده با پایتونی که کاربر از قبل دارد تداخل می‌کند؛
- و با چرخهٔ انتشار ما کهنه می‌شود، نه با چرخهٔ خود وندور.

به جایش، نصاب رسمی خودِ وندور دانلود می‌شود.

## از نظر امنیتی

هر فایل دانلودشده پیش از اجرا از روی **امضای Authenticode** بررسی می‌شود:

| فایل | باید امضای چه کسی را داشته باشد |
|---|---|
| `python-3.12.x-amd64.exe` | Python Software Foundation |
| `node-v20.x.x-x64.msi` | OpenJS Foundation |
| بوت‌استرپر WebView2 | Microsoft Corporation |

اگر امضا نخواند، فایل **اجرا نمی‌شود** و پاک می‌شود. بررسی روی ناشر است نه روی
هش ثابت، تا وصله‌های نسخه‌ای وندور نصب را نشکنند.

همهٔ مراحل در این فایل ثبت می‌شود:

```
data\logs\setup.log
```

## اگر کار نکرد

| نشانه | کجا را ببینید |
|---|---|
| پیش‌نیاز نصب شد ولی پیدا نمی‌شود | معمولاً `PATH` است. یک‌بار sign out و sign in |
| نصب Node نیمه‌کاره ماند | احتمالاً UAC رد شده. `AURION.exe --setup` را دوباره بزنید |
| هر چیز دیگر | `data\logs\setup.log`، و بعد `data\logs\engine.log` و `data\logs\desk.log` |

`AURION.exe --setup` را هر چند بار که بخواهید می‌توانید اجرا کنید؛ فقط سراغ
چیزی می‌رود که هنوز نصب نیست.

## برای کسی که خودش سیستم‌ها را ایمیج می‌کند

اگر رانتایم‌ها را خودتان از قبل روی ایمیج می‌گذارید و نمی‌خواهید موقع نصب
پنجره‌ای باز شود:

```
msiexec /i AURION-1.0.0-x64.msi /qn AURION_SKIP_PROVISION=1
```

## جزئیات فنی

Node.js به شکل `.msi` منتشر می‌شود و ویندوز اینستالر با قفل `_MSIExecute` اجازهٔ
نصب تودرتو نمی‌دهد. برای همین پیش‌نیازها **داخل** تراکنش MSI نصب نمی‌شوند، بلکه
`AURION.exe --setup` به عنوان یک پروسهٔ جدا بعد از پایان تراکنش اجرا می‌شود.

کد مربوطه:

| فایل | کارش |
|---|---|
| `installer/src/Prerequisites.wxs` | تشخیص با `AppSearch` و ساختن `AURION_PROVISION_NEEDED` |
| `installer/src/Actions.wxs` | اکشن `AurionProvisionRuntimes` و زمان‌بندی‌اش |
| `installer/src/ui/AurionUI.wxs` | صفحهٔ Environment check و دکمهٔ Finish |
| `installer/window/Prerequisites.cs` | دانلود، بررسی امضا، نصب واقعی |
| `tests/installer-prereqs.test.js` | جلوگیری از برگشت این باگ (`npm run test:prereq`) |
